# Litoral Data Insights — Painel de Dados Econômicos da Baixada Santista

> Transformando dados públicos em inteligência para pequenos negócios da região

## Sobre o Projeto
Os dados sobre renda, população e empresas da Baixada Santista existem mas estão espalhados em dezenas de sites, sem organização e quase impossíveis de usar. Empresários locais tomam decisões no "achômetro" e perdem oportunidades por falta de informação clara.

Este projeto é um pipeline completo que **coleta, limpa, cruza e visualiza** dados públicos reais das cidades de São Vicente, Santos, Guarujá, Cubatão, Praia Grande e região transformando números brutos em conhecimento útil para tomada de decisão.

##  Tecnologias
-  **Python** — Extração, limpeza e transformação de dados
-  **SQL** — Cruzamento, validação e análise de dados
-  **Power BI** — Visualização interativa e painéis de negócio
-  **ETL Completo** — Extração → Transformação → Carga → Visualização

## Fluxo do Projeto
1. **Extração** → Coleta de dados públicos: IBGE, SEADE, Prefeituras, RAIS/MTE
2. **Transformação** → Limpeza, padronização, tratamento de valores nulos e inconsistentes
3. **Cruzamento** → Renda × População × Empresas × Turismo identificando oportunidades
4. **Visualização** → Painel interativo no Power BI com mapas, gráficos e filtros

## Objetivo
Dar aos pequenos e médios empresários da Baixada Santista uma ferramenta simples e acessível para entender onde estão seus clientes, quais setores crescem e onde existem oportunidades de negócio sem precisar ser especialista em dados.

## Dados Utilizados
- Renda média por bairro
- População e densidade demográfica
- Quantidade de empresas por setor
- Taxa de emprego e formalidade
- Fluxo turístico e movimentação econômica
